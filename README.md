
# Actividad 4 - Validar Credenciales

Este proyecto fue realizado como parte de una
actividad universitaria de programación en Python.

## Descripción

La aplicación permite validar el usuario y la
contraseña ingresados mediante una interfaz
gráfica desarrollada con Tkinter.

## Funciones principales

1. Capturar las credenciales del usuario.
2. Validar los datos utilizando variables de entorno.
3. Mostrar un mensaje de acceso correcto o incorrecto.

## Tecnologías utilizadas

- Python
- Tkinter
- python-dotenv

## Cómo ejecutar

1. Instalar Python.
2. Crear un entorno virtual.
3. Instalar dependencias con:
   pip install -r requirements.txt
4. Crear un archivo .env con:
   APP_USER=usuario_prueba
   APP_PASSWORD=clave_prueba
5. Ejecutar main.py.
